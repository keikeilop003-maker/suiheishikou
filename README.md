# SNSで暴れるナラティブ

高校国語の授業で使う、水平思考型のナラティブ体験アプリです。

3つの実例について、事実Aと事実Bの間にあるストーリーを生徒が投稿します。投稿はFirebase Firestoreに保存され、同じURLにアクセスした参加者間で共有されます。

## 公開ページ

- 投稿ページ: `index.html`
- 真実ページ: `truth.html`

## 管理機能

管理PASSは `1121` です。管理モードでは投稿の削除、全削除、並べ替え、ピン留めができます。

## Firebase

このアプリは無課金運用のため、Firebase Hosting + Firestore直接書き込みで構成しています。Cloud Functionsは使っていません。

Firestoreのセキュリティルールは授業利用向けの簡易設定です。広く一般公開する場合は、管理操作の認証方式を強化してください。
