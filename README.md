# 脳の「省エネ」vs「大暴れ」実験アプリ

高校生向けの国語授業で使う、A/B投票型の情報リテラシー実験アプリです。

同じ架空ニュースに対して、次の2つの文章を読み比べます。

- A: 多角的で、結論を急がないジャーナリズム・スタイル
- B: 敵味方がはっきりした、スッキリ読めるSNSナラティブ・スタイル

生徒は「どちらが正しいか」ではなく、「どちらが読んでいてスッキリしたか」で投票します。投票結果はリアルタイムで棒グラフに反映されます。

## ローカル起動

```powershell
node server.js
```

- 教師端末: `http://localhost:3000`
- 生徒端末: 起動時に表示される `Students/LAN` のURLを同じWi-Fi内で共有

## 管理機能

ヘッダー右側の管理PASSに `1121` を入力すると、投票をリセットできます。

## 授業の流れ

1. 架空ニュースを確認する。
2. A/Bの文章を読み比べる。
3. 「スッキリ読めた方」に投票する。
4. クラスの集計を見る。
5. 種明かしを表示し、脳の省エネと情報吟味の関係を振り返る。

投票データは `submissions.json` に保存されます。
